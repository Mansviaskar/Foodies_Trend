🍴 Foodies Trend — Food Recipe Discovery Website

Foodies Trend is a responsive food recipe discovery website designed to help users explore recipes across different meal categories through a simple and interactive interface.

The website provides an organized collection of recipes with category-based browsing, search functionality, filtering, and visually appealing food cards.

🔗 Live Demo: https://foodies-trend.netlify.app/

✨ Features

* 🔍 Recipe search functionality
* 🍳 Breakfast recipes
* 🍛 Lunch recipes
* 🍿 Snacks recipes
* 🍰 Dessert recipes
* 🏷️ Category-based filtering
* 🖼️ Food images and recipe cards
* 📱 Responsive design
* ⚡ Fast client-side interactions
* 🎨 Clean and user-friendly interface

🛠️ Tech Stack

* HTML5 — Website structure
* CSS3 — Responsive styling and layout
* JavaScript (ES6) — Interactivity, search and filtering
* Netlify — Deployment

🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Mansviaskar/Foodies_Trend.git
cd Foodies_Trend
```

Run the project

Since this is a frontend-based project, you can open:

```text
index.html
```

directly in your browser.

For the best development experience, use **VS Code Live Server**.

🔄 User Flow

```text
Home Page
    ↓
Choose Food Category
    ↓
Browse Recipes
    ↓
Search / Filter
    ↓

```
